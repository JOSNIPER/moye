## 三、启动步骤（演示时照做即可）

### 1. 确认数据库和后端

MySQL 服务 `MySQLDefaults` 需处于运行状态（默认自启）。后端可用两种方式启动：

- **方式 A（推荐，符合板书）**：用 IDEA 打开 `backend`，直接运行 `SpringbootSchemaApplication`
- **方式 B（命令行）**：
  ```bash
  "E:/02-Dev/JDK/8/bin/java.exe" -jar "C:/tools/backend/springbootpkh49.jar"
  ```
  注意用 JDK8 的绝对路径启动（系统 PATH 里默认是 JDK21，直接用 `java -jar` 可能不兼容）。
  ⚠️ **演示数据已打进这个 jar**。运行副本特意放在 `C:/tools/backend/`（非 OneDrive 同步目录）——jar 放 OneDrive 同步范围（Desktop/前端项目）里运行会被同步锁文件导致进程闪退。若改过后端重新打包，把新 jar 复制到 `C:/tools/backend/springbootpkh49.jar` 覆盖即可，打包会自动带上 `src/main/resources/static/upload/` 里的演示文件。

看到日志 `Tomcat started on port(s): 8080` 即成功。

### 2. 启动两个前端

在 `admin` 和 `front` 目录分别开两个终端执行：

```bash
cd admin
npm run dev        # 后台 → http://localhost:5173

cd front
npm run dev        # 前台 → http://localhost:5174
```

> Node 版本：本机 CMD 是 Node 26.13.0，已实测 Vite 6 完全兼容。项目里放了 `.nvmrc` 声明版本。
> 如果 `npm install` 提示 esbuild 的 install-scripts 警告，可忽略，不影响运行。

## 五、技术实现要点（答辩可讲）

1. **前后端分离 + 代理**：Vite 配 `server.proxy` 把 `/springbootpkh49` 转发到 `localhost:8080`，开发时无需处理跨域，部署时前后端同源也不用改代码。
2. **统一请求封装**：axios 拦截器自动注入 `Token` 请求头；后端业务码在 body 的 `code` 里（`0` 成功、`401` 未登录），拦截器统一处理错误提示和登录过期跳转。
3. **Element Plus 组件库**：按老师要求全程使用——表格、表单、弹窗、分页、菜单、卡片、消息提示等，中文化 locale 配置。
4. **CRUD 工厂函数**：后端 8 张表接口结构完全一致（`page/list/info/save/update/delete`），前端用 `crudApi(resource)` 工厂生成 API，避免重复代码。
5. **路由懒加载**：各页面用 `() => import()` 按需加载，构建产物分包。

## 六、踩坑记录（已解决）

- **端口 5173 被占**：`vite.config.js` 设了 `strictPort: true`，端口被占会直接报错而非悄悄顺延，保证老师看到的地址确定。
- **Node 双版本**：Node 22 与 Node 26 均实测兼容 Vite 6；之前测试误用 Node 22 是因为 Git Bash PATH 里 WorkBuddy 自带的 Node 22 优先级更高，用 `/e/02-Dev/Node` 前置 PATH 或绝对路径调用即可用到 Node 26。
- **后端 8080 占用**：曾因旧会话残留 java 进程占用，清理后重启解决。
- **文件上传**：后端返回 `{code:0, file:"时间戳.扩展名"}`，前端拼接 `/springbootpkh49/upload/文件名` 访问。
- **模糊搜索参数（重要）**：后端约定字段名**带 `_like` 后缀才做模糊匹配**，不带是精确匹配。所以名称搜索必须发 `wendangmingcheng_like=关键词`，类型筛选发 `leixing=PPT`（精确）。之前后台/前台都误用了不带后缀的参数导致搜索失效，已全部修复。
- **list 与 page 接口结构**：`/{表}/list` 和 `/{表}/page` 返回的都是 `{code:0, data:{total, list:[...]}}`，`data` 不是裸数组——做类型统计时取 `res.data.list`。
- **排序参数**：`sidx=字段名&order=ASC|DESC`，后端 `Query` 类会做 SQL 注入过滤，可安全使用。
- **演示文件**：5 个真实命名的演示文件（使用手册/入职指引 2 个 Word、季度工作汇报 PPT、统计台账/通讯录 2 个 Excel）已打入 jar 的 `BOOT-INF/classes/static/upload/`，并同步到 `src/main/resources/static/upload/`；数据库对应 5 条文档记录（fujian 用相对路径 `/springbootpkh49/upload/文件名`，经 Vite 代理可访问）。前台点「查阅」可直接打开。
- **前台 token 自动续期**：front 的 axios 响应拦截器检测到 `code:401` 时自动清除旧 token、静默重新登录并重试原请求（`_retried` 标记防死循环）。此前 token 过期（约 1 小时）会导致前台页面静默变空，已修复。
