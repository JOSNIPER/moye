## 一、改版目标与参考对象

### 目标
把原来"学生作业感"的页面（前台紫渐变营销 Hero、后台普通蓝表格）升级为**国内大厂同类型产品的专业工作平台观感**，同时保证：

- 功能全部真实可用，不造假功能

### 参考对象与取舍

| 大厂/开源产品 | 借鉴了什么 | 为什么没照搬 |
|---|---|---|
| 飞书云文档 | 侧边导航分组、文件卡片、列表视图、悬停操作、详情面板 | 协作评论/权限面板需要后端支持，本系统没有 |

## 二、统一设计系统（前后台共享）

两个项目的 `src/styles.css` 写入了同一套 CSS 变量，并覆盖了 Element Plus 主题：

| 变量 | 值 | 说明 |
|---|---|---|
| `--brand` | `#0d9f6e` | 主色（墨绿），按钮/选中态/图标主色 |
| `--bg-page` | `#f5f6f8` | 页面浅灰底 |
| `--bg-card` | `#fff` | 卡片白底 |
| `--text-1/2/3` | `#1f2329 / #4e5969 / #86909c` | 三级文字层级 |
| `--border` | `#e5e6eb` | 边框 |
| `--radius-m` | `10px` | 卡片圆角 |

Element Plus 的 `--el-color-primary` 系列一并覆盖，所以所有组件（按钮、标签、分页、菜单）自动统一到新主色。这一步解决了原来"前台紫渐变 + 后台 Element 默认蓝"的风格割裂。

## 六、答辩可讲的设计要点

1. **信息架构**：参考飞书/腾讯文档的工作台范式——「全局导航 + 分类侧栏 + 内容区」，比传统"顶部菜单 + 大 Banner"更适合文档系统
2. **设计系统**：用 CSS 变量统一色彩/圆角/阴影/间距，并覆盖 Element Plus 主题变量，一次定义前后台一致
3. **技术取舍**：明确区分"可借鉴的视觉语言"和"后端撑不起的功能"（在线编辑/权限/目录树），体现工程判断力
4. **组件化**：详情抽屉、卡片视图、分类统计都是独立可复用的模块；菜单从路由配置自动生成
5. **零后端改动**：所有优化在前端完成，接口、数据库、业务逻辑完全未动，风险可控
